# Dossier des assets (icônes, splash, images)

Pour que le projet fonctionne, ajoutez ici les fichiers suivants (facultatif pour le développement) :

- `icon.png` → Icône de l'app (1024×1024 px)
- `splash.png` → Écran de démarrage (2048×2048 px)
- `adaptive-icon.png` → Icône adaptive Android
- `favicon.png` → Version web (si besoin)

En attendant, Expo utilisera des assets par défaut.
